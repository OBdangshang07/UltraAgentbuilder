# 界面与操作流程

## 第一次使用

进入单机创造模式世界，按 **V** 打开面板。还没有连接制作来源时，先点左下角的 **加载示例**，可以免费体验预览和摆放。

制作自己的建筑时，只需完成四步：

1. **描述建筑**：在创作页写建筑类型、风格、规模和希望保留的细节。
2. **生成预览**：选择已登录的本机来源、模型和制作方案，点击生成建筑，再检查本次调用预算。返回确认页不会调用模型。
3. **到世界中摆放**：右侧查看成品后，点击到世界中摆放。滚轮推远或拉近，R 旋转，M 镜像，K 锁定。
4. **确认建造**：锁定后按 Enter 打开最终确认。也可回到摆放页检查位置和覆盖策略，再打开建造确认。

生成确认与世界建造确认是两个独立步骤。预览、调整位置、切换页面不会授权修改世界。

## 四个主入口

| 页面 | 主要用途 |
| --- | --- |
| 创作 | 写描述、选择来源和模型、生成新建筑；参考图片是可选项 |
| 摆放 | 调整位置、旋转和镜像、检查覆盖策略、确认建造 |
| 作品 | 加载已有版本、导入建筑资产和导出当前版本 |
| 工具 | 环境选区、修改当前建筑、查询原任务、连接诊断与世界恢复记录 |

创作页把快速单次与 Lite、Pro、Max、Ultra 放在同一个制作方案选择器里。选项直接展示说明和调用上限。四档控制拆分与复核深度，不保证特定质量或成功率。高级设置中的兼容生成方式仍可明确选择。

## 按需展开

- **高级设置**：实验质量流程、图像复核、提供方恢复、额外修复和输出预算。收起不重置设置；最终生成仍须检查实际预算。
- **精确调整与显示**：X/Y/Z、移动步长、定位撤回、楼层剖切、透明度与投影草稿。
- **参考图的视向与已知尺寸**：不知道时可以留空，不用编造尺寸。
- **参考图的草稿与更多操作**：保存、恢复、排序、移除及兼容准备记录。

主面板可用 Tab / Shift+Tab 在控件间移动，滚动区域会跟随焦点。切换主页面会记住各页滚动位置，建筑描述和未应用坐标会保留。Enter 在描述框换行，Ctrl+Enter 开始生成预检。

已添加参考图时，主按钮会变为 **检查参考图**，先检查图片，再经过独立预算和发送确认；Ctrl+Enter 使用相同流程，不会忽略图片改成纯文本生成。请明确选择四档组件制作方案与支持图片的 Codex 模型，界面会提示缺少哪项设置。

## 环境选区

选区面板分为选区、分析、改造、记录和高级五页。先框周围环境，再在里面框改造范围；保护区域可选。通常直接到游戏中用鼠标框选，精确坐标默认收起。

分析页准备环境理解任务；改造页准备区域改造或参考图与场地联合任务；记录页查看原任务。已有任务的兼容发送入口集中在高级页。不同任务仍使用各自的审核与确认，不会因为切页而自动发送、升级或重试。

## 状态与限制

顶部和底部会提示当前该做什么：连接来源、填写描述、等待制作、摆放或确认建造。生成失败时会明确标出仍在显示已有建筑；状态未知时先查询原任务，避免重复调用。

本次为 Alpha 界面改版。选区和多模态组合仍属实验功能。完整 Ultra 大型任务的原生崩溃、真实模型一次完成、物理输入法及多人等原有验收边界不因界面变化而视为通过。
