# Independent coupled native handoff

The coupled server lease retains the exact original audit, full input,
compiled reconstruction, preview and fresh BEFORE. An archived-source rebuild
independently checks bytes during plan preparation, but the prepared plan keeps
the original server-compiled object and baseline; it does not promote that
rebuild into a replacement world authority.

The opaque handoff requires a separately issued final APPLY ticket for the
same confirmation owner, player and complete binding. The ticket is one-use,
short-lived and independent from legacy tickets, SEND consent and the UNDO
purpose. Consumption is synchronized; a public binding or equal replacement
owner cannot create or reuse it. The short final-confirmation window is not a
generation lifetime, model-output or provider-token limit.

Detachment rechecks the live original task and BEFORE, consumes the ticket,
revokes the old Capture lifetime and moves its original watch/chunk fence into
a private-constructor native origin. Read-only reports grant no write access.
There is no snapshot refresh or adoption of an archive or another task.

The native source, placement/undo gateway and player confirmation UI remain
separate required integrations. This handoff alone is not a runnable building
workflow, native physics proof, installed-server acceptance or a release.
