# Coupled normal companion startup

The paired CLI/builtin companion enables the versioned coupled preparation
and SEND lane without a separate manually launched Bridge or hidden developer
flag. Imported `startBridge` defaults remain disabled. Request JSON and config
fields cannot override those immutable process-owned startup choices.

Availability is not a model invocation or a world lease. Exact original
pictures, advertised image model/effort, shared tier budget, disclosure,
independent one-use SEND and original native renderer readiness remain
mandatory. Unknown outcomes only observe the original task; no automatic
resubmission or legacy consent transfer is introduced.

Capabilities advertise that the bundled player UI and server placement
implementation exist. They deliberately do not attest any current server
baseline or authorize world writes. Actual application and protected undo
still require their separate server-owned final confirmations.

Free CLI tests launch and gracefully close the original owned child, check
authenticated loopback availability, reject malformed/unconfirmed requests,
and verify empty original job histories. They do not prove real model output,
installed player interaction, shaders, physical input or saved world state.
Those gates must use this same final candidate before a binary release.
