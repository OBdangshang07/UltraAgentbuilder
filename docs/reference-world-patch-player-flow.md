# Joint world-patch player flow

The reference-image editor and exact joint content freeze now lead to a separate
joint SEND review, original-only local history and result pages. The text-only
path is unchanged. Detaching pictures remains an explicit task-page choice.

The immutable player handoff checks the frozen preparation, original manifest,
ordered images/annotations, actual image capability and runtime. A new model
advertisement must match the reviewed one, not only its model name. Changing
world, selection, context, images, prompt or selected model invalidates unsent
approval. Page close/re-entry/resize cannot repeat a SEND.

The explicit SEND uses the existing durable joint claim, exact image freeze and
two original-server fences. Unknown results retain the original identity and
cannot trigger another image transfer or model call. Automatic result polling
is GET only. A separate confirmation may observe the bound original provider
turn; it is not a retry, replacement, new budget or world-baseline refresh.

History reads the independent joint reference store. It does not turn a saved
reference into dispatch proof. Missing/corrupt records are preserved, not
recreated or replaced. Original checked candidates can enter the existing
original-coordinate difference projection only after exact candidate/image and
same-server snapshot checks. Preview loading grants no world writes; the shared
fresh BEFORE/physics check and explicit final world confirmation remain required.

This is still the default-disabled **one-call development protocol**. These pages
do not deliver the complete Lite/Pro/Max/Ultra reference-and-context design
pipeline, enable ordinary startup, certify a release or prove real multimodal
quality. Those gates require the versioned shared design/prototype/component/
native-review workflow and exact-package game/real-model acceptance. The complete
roadmap remains in scope.

Free tests cover immutable handoff data, capability/image swaps, honest status
wording, sole production-Java HTTP dispatch, original history/results, server
fences, closed/stale pages and uncertain outcomes. They do not prove in-game
layout, Chinese IME, shader pixels, actual design quality or world transactions.
