# UltraAgentbuilder 发布规则

每个完成的阶段单独提交并推送，记录该阶段做了什么、通过哪些验证、还有哪些限制。只推送已经审查过的源码、模拟测试和公开说明；未知或未结束的真实任务不能被标为成功。

## 公开范围

允许提交模组源码、内置 Bridge 源码、数据协议、提示词规则、离线测试、构建配置、公开文档及上游 Gradle Wrapper。

不得提交账号或 API 凭据、连接令牌、模型会话和原始私人回答、私人参考图片、OAuth 临时地址、存档、测试实例、生成成品或包含本机身份信息的内部报告。`.gitignore` 仅是第一层防护，提交前仍须检查暂存内容。

## 阶段交付

1. 完成有明确边界的改动，保留原始证据，不热改在途测试来源。
2. 运行与风险相称的离线和游戏验证，明确跳过项。
3. 检查暂存差异与公开范围，运行发布检查。
4. 提交并推送，核对 GitHub 远端提交与本地提交一致。

```powershell
npm run check:public
git diff --cached --check
git diff --cached --stat
git push origin main
```

源代码里保留兼容协议名不视为命名遗漏。没有验收的候选 JAR 不作为正式 Release 发布，也不覆盖玩家的正式安装。
