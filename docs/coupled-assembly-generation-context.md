# Explicit coupled design context

`CoupledAssemblyWorldContext` is a separate opaque original-snapshot context,
not a JSON switch that upgrades old static-v2 SEND or world-write authority.
It retains the complete original exact baseline, W/P/C, world, origin, limits
and revisions. Its new target catalog, fixed coupling policy and generation
rules have an independent identity; the old baseline evidence protocol hash
does not become permission for the new targets.

The shared design-stage runner chooses rules from the actual checked brand.
Legacy checked contexts receive the exact old data/rules. New checked contexts
disclose whole matching new-door pairs, final UP-face support, canonical dry and
unpowered stairs/slabs/trapdoors, excluded leaves/light, and protected existing
coupled BEFORE states. Neither mode may silently omit design requirements,
refresh the capture, move scope, or treat a part/preview as placement consent.

This wires **internal stage prompting only**. New preparation/archive/SEND and
candidate/HTTP/client/server/confirmation integration are still required before
a player can use this mode. The old public task path is not automatically
switched, failed tasks are not adopted, and no installed-game, protected undo,
Iris or physical-save acceptance is asserted.
