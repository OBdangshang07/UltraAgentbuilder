# Independent coupled preparation and frozen source

The coupled world/reference path has a distinct v1 preparation, archive and
SEND format. It binds the original reference pixels/annotations, exact captured
world scope and baseline, selected advertised image model/effort, unchanged
shared call budget, complete-native coupling policy and generation protocol.
Legacy full-v2 or one-call consent does not transfer to this new purpose.

Preparation and source freezing are free, local data operations. Files are
exclusively created and flushed; source pins and metadata commit last. Reopened
complete archives are independently reconstructed from every original context
file and job-owned reference. Unknown/partial files, mismatched pins and altered
scope remain errors, not a reason to evict, overwrite, adopt or refresh them.
Reading an original archive after expiry cannot create new dispatch permission.

This milestone does **not** implement the new registry/execution owner,
candidate publication, HTTP/client workflow, native source/final confirmation,
group-protected undo or installed-game acceptance. It does not contact a model,
reserve a call, render/compile a replacement building or modify a world. Those
gates remain required, including exact same-asset placement and physical save.
