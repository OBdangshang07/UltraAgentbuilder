# 0.4.10 可安装预览版

本次提供 Windows x64、Minecraft Java 1.20.1 的可安装预览包，用于在单机创造模式中体验本机 Agent 生成、世界投影和确认建造。它不是稳定正式版，完整 Ultra 大型场景的无人值守完成能力仍未验收。

[下载预览包](https://github.com/OBdangshang07/UltraAgentbuilder/releases/tag/v0.4.10-preview.20261027)

## 安装

1. 准备 Minecraft **1.20.1**、**Java 17** 和 **Fabric Loader 0.16.10 或兼容版本**。
2. 退出游戏，解压下载包，将 `mods` 内的主模组 JAR 放进实例的 `mods` 目录。
3. 包内另附 Fabric API **0.92.5+1.20.1**。实例没有 Fabric API 时一起复制；已有兼容版本时保留原来的，避免安装两份。
4. 移出同一模组的旧 JAR，再启动游戏。旧名 Voxel Studio 与 UltraAgentbuilder 使用相同的 `voxel_studio` 模组 ID，不能同时安装。保留原数据目录。

主 JAR 已内置本地 Bridge、Windows Node 运行时和生成规则，**无需另装 Node、启动 Bridge 或复制 skills 文件夹**。Minecraft、Java、Fabric Loader 及所用 Agent 不包含在下载包中。

## 第一次使用

1. 打开一个单机创造模式测试世界，按 **V** 打开面板；冲突时在 Minecraft 控制设置中重新绑定。
2. 先加载内置示例，检查面板预览、世界投影与最终确认。这一步不调用模型。
3. 在本机安装并登录受支持的 Agent，回到面板刷新制作来源，选择该来源实际提供的模型及推理强度。
4. 输入建筑描述，初次建议使用 Lite 或 Pro。面板内 **Ctrl+Enter** 生成，**Enter** 换行。生成可能消耗所选 Agent 的额度。
5. 成品就绪后进入世界投影：滚轮调整距离，**R** 旋转，**M** 镜像，**K** 锁定，**V** 返回面板。锁定后按 **Enter** 打开建造确认，再明确确认应用。控制设置和面板帮助列出完整按键。

第一次在重要存档使用前请备份世界。初次排查投影或渲染问题时，建议先手动关闭光影，再单独检查光影兼容性。

## 本次收尾包含什么

- 打包已有主 JAR、配套 Fabric API、第三方许可和校验值，保持原包字节。
- 保留 Lite／Pro／Max／Ultra、Agent 检测、投影定位与既有选择、参考图入口。
- 包含门组原生校验的方法映射修复，以及此前正常内置伴侣的联合流程入口修复。
- 不把模型失败或未知回执自动当作可重新收费的任务，不自动接管旧失败任务。

主 JAR 的模组版本仍是 `0.4.10-alpha`，源码固定为 `c169b388545ab187cba3f6f9a656c15c8bdc79c8`；发行标签用于区分本次预览包，没有重编译或更改 JAR。
