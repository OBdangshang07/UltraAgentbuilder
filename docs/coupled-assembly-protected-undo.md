# Complete-group protected undo core (not installed yet)

The independent coupled inverse journal accepts only the original one-use
live sealed forward witness. Archive inspection exposes immutable facts,
not a new writer, native lease, recovery capability or final confirmation.
The unmodified forward journal must remain a physical sibling.

Undo reverses complete original groups. A door's upper member is restored
before its lower, synchronously in the same step and durable intent. Both
members receive one common restored/preserved disposition. Neither packet
boundaries, cancellation nor remaining step capacity may split the pair.

All targets and original six-neighbor expectations are checked before any
member changes. A later edit to either half preserves both. A preserved door
also protects its written support from inverse removal. Explicit inverse
native group/state/support preflight and final checks remain mandatory.
An unknown second write or disk receipt retains the entire unresolved
intent, never a half receipt, automatic retry or newly adoptable origin.

The source uses a new operation epoch only to guard that explicit undo;
it does not replace the original capture, selection, source or AFTER states.
All persistence and placement authority flags remain false. The core still
needs production native sources, server mutual exclusion, UI consent,
installed-game/Iris and same-asset physical save verification. Synthetic
Source booleans do not prove vanilla support behavior or world durability.
