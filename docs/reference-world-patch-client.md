# Joint client contracts (development-only)

The joint reference-image/world-patch protocol now has independent Java
preparation, frozen-task, original-job/status and candidate-download verifiers.
These are not aliases for legacy text-only confirmations or tasks.

Original world capture, the retained canonical reference manifest, selected
image-capable model advertisement, runtime and independent joint consent
establish the pins. A status or download cannot choose another snapshot,
image set, capability, model or source. JSON is bounded, fatal-decoded and
duplicate-key checked; exact versions/fields and original response hashes
are required. Local stop diagnostics are not provider-terminal proof.

GET-only download methods and an original-coordinate loader are implemented.
Only a fully checked candidate joins the common sealed preview/audit value.
It carries the original response to the existing server-owned capture checks,
not downloaded world-write instructions or a newly sampled baseline. Loading
a preview does not invoke a model or authorize placement. World, capture,
page and selection changes revoke publication of an asynchronously read result.

The original-coordinate transaction path still requires its independent
server-side proposal audit, fresh BEFORE comparison and final in-game consent.
Both legacy and joint download types retain zero placement authority. Their
protocols and image identity remain distinct before the common audit boundary.

## Verification and limits

Free verification on a per-file-pinned source copy completed the full Java
test/build: 552 tests, 551 passed, one skipped, zero failures/errors. All
31 newly added joint tests ran, including actual production HTTP/worker bytes
with synthetic provider transport and pictures. Associated Node regression
passed 76/76; syntax and publication/branding checks passed. The complete
Node suite and this commit's independent CI are separate gates, not implied
by those targeted results.

This is a source milestone, not an installed or certified release. Normal
joint preparation/SEND/history/observation UI and durable client claims are
not wired yet. The process opt-in remains default-disabled. A bounded
one-call patch lane is not the full Ultra design/prototype/component/visual
review workflow; that shared reference/context integration remains required.

Player-world safety, shader compatibility, input, performance, installation,
complex architectural quality and independent review still need acceptance
against the final integrated package. No private provider records, images,
worlds, generated fixtures or candidate JARs are published with this milestone.
