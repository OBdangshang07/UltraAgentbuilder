# Grouped forward transaction core

The new `CoupledAssemblyJournal`/`CoupledAssemblyExecution` protocols are
independent from the legacy static whole-v2 transaction. The journal prepares
from the original capture and **complete** native/parts/preview input, rebuilds
it independently, and retains those exact source bytes. A metadata report,
copied hash or disk review cannot construct a live owner or grant world writes.

Fixed maximum-512-write intents end at complete original group boundaries.
Execution order promotes each matching upper door immediately after its lower;
neither 8192-row transport parts, remaining tick budget nor cancellation can
split a door. If two writes do not fit a step, both wait for the next step.
The minimum supported per-step count is explicitly two. The time budget applies
between groups; a begun two-cell synchronous group is not preempted by it.

All members and original six-neighbor facts are checked before beginning a
group. Native registry/support checks must be supplied by the eventual original
server source. Exact AFTER states, revision continuity and support must hold
after the complete group. Only complete groups enter receipts. Failure after a
possible partial mutation retains the original unresolved intent, requires
review, and does not seal a half group, automatically replay or issue undo.

Exclusive flushed files preserve partial/unknown publication. Read-only review
rebuilds every original input and deterministic packet, rejects rehashed half
receipts, missing/orphan events and unknown members. It creates no resume token.
Neither a journal receipt nor synthetic Source completion proves physical save
durability or crash-atomic publication.

A sealed witness can be obtained only from the original normally closed live
ledger and its exact complete-group prefix. It retains immutable original
source/event hashes and rejects changed, rehashed, missing or added events. The
engine's cached one-use undo origin requires that same witness; an archive path,
matching hash, read-only Review or ambiguous forward write cannot create it.
This witness does not itself open an undo source or provide final undo consent.

This is **not yet the installed game path**. Still required: independently
versioned candidate/preparation/HTTP/client/consent integration, fresh server
BEFORE and native lease, production group/state/support access, complete-group
protected undo, installed UI/Iris verification and same-asset placement/save.
Existing coupled BEFORE edits remain protected. No old failed task is revived.
