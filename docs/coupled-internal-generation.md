# Independent coupled generation, not a player release

The internal coupled entry now uses the same durable reference-analysis,
concept, component, correction and current native-review pipeline as complete
generation. It requires its own versioned pixel input and full-budget SEND;
ordinary image generation and legacy full v2 confirmation cannot transfer.
The model receives the checked new coupled rules at every design stage.

The first normal final compilation retains the original accepted SceneSpec.
The complete existing ledger, selected references, mandatory package and native
render verifier is shared with the legacy path. Its reviewed ordered palette,
dimensions, cell bytes and source must match the final native bundle. No
replacement scene, reduced proof or unreviewed compilation is promoted.

Candidate publication checks the complete native coupling plan before writing
any provisional part. It keeps the original manifest/cells bytes, complete plan,
all part/preview hashes and all original proof pins. Binding is derived only
after candidateHash, outside the candidate's own hashed member list. A bounded
collector retains preview hashes rather than every expanded preview geometry.
Reads reconstruct the complete result before exposing even one selected part.
Metadata commits last; failed writes keep their claim and partial files.

An internal start claim is consumed before any call. It is explicitly NOT a
live original registry capability or server owner. Starting again after a
failed, cancelled or completed run cannot replay the generation. A completed
result is read-only. The original shared tier budget still includes all calls.

An independent internal registry and runner now own the new task namespace.
Only their one-use process-local execution can start a registered job. Duplicate
SENDs/status reads reuse the original record; reopened registries cannot adopt
execution. The first pending original call binds start expiry and fingerprint;
subsequent original calls retain that full-task lifetime, not a hidden timeout.
Completed proof includes original request, owner, dispatch and start records.
The bounded resource lane returns exact-file payloads for the complete native
manifest/cells/plan and parts. It does not borrow legacy warm-verifier receipts.

This entry is not exposed through HTTP or the player UI yet. Client downloads,
original server Capture/SEND retention, native
lease, final consent, mutual exclusion, installed projection, same-asset actual
placement/undo and physical-save acceptance remain necessary. Existing coupled
BEFORE editing is still protected, not silently enabled. Synthetic tests are
transport/fault evidence, not model reliability, image understanding, design
quality, installed gameplay or a certified binary release.
