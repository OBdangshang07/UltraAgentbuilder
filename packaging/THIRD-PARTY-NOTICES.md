# Runtime and dependency notices

The Windows companion bundles Node.js 22.19.0. Its license and the notices for
its bundled third-party components are included in
the JAR entry `voxelstudio-bundle/runtime/NODE-LICENSE.txt`, also extracted to
`voxel-studio/bundles/<version-hash>/runtime/NODE-LICENSE.txt` on first use.

This package does not bundle Minecraft, Java, Fabric Loader, Fabric API, or
Codex CLI, Claude Code, or DeepSeek Harness. Install these separately from their official distributors and use
them under their respective licenses and account terms.

Tested development dependencies: Minecraft 1.20.1, Java 17, Fabric Loader
0.16.10, Fabric API 0.92.5+1.20.1, Yarn 1.20.1+build.10, Fabric Loom 1.10.5,
Gradle 8.12.1, and Codex CLI 0.147.0. Development tools are not included in the
runtime package.

Claude Code 2.1.229 was probed read-only for discovery and capability flags.
Real Claude generation is not yet validated; the package includes only the
project’s experimental adapter, not the Claude executable or account data.

DeepSeek Harness (@deepseek-ai/dsh) 0.1.5-rc.1 was validated through its
installed sdk-minimal JSONL runtime: a local fake-provider test and one real
deepseek-flash generation. Version 0.1.7-alpha.1 adds Messages-transport
compatibility, verified against the installed SDK with loopback provider
fixtures (max effort, token budgets, usage, truncation and no-retry errors).
This offline verification is not evidence of a successful paid generation.
It is loaded from the user's separate installation,
not bundled. No DeepSeek credentials, user plugins or private SDK sessions are
included. See https://github.com/deepseek-ai/deepseek-harness for upstream
licensing, installation and account configuration.

Interaction references: Litematica's layer/movement documentation and Axiom's
Gizmos/Move documentation. No Litematica or Axiom code/assets are included;
this does not imply endorsement, binary interoperability, or compatibility
testing with either mod.

No upstream example HTML, user Minecraft world, Codex login files, Bridge
pairing token, or private generation history is included. The included sample
BuildingSpec is generated by this project's sample module.
