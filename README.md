# UltraAgentbuilder

UltraAgentbuilder 是一个开发中的 Minecraft Fabric 模组：在游戏中连接本机 AI Agent，用描述生成建筑，进行世界投影预览，再经玩家确认放置。项目原开发名为 Voxel Studio，目前处于 Alpha 阶段，不承诺所有大型建筑任务都能无人值守完成。

这个公开仓库包含模组、内置本地 Bridge、生成规则和离线测试源码，不包含账号凭据、私人图片、模型会话、建筑生成记录或 Minecraft 存档。

## 当前功能

- 本机 Agent 检测和模型选择；包含 Codex、Claude Code 和 DeepSeek Harness 适配器，各来源的实际验证范围不同。
- Lite、Pro、Max、Ultra 四档生成工作流，支持组件化制作、有限预算纠错和原始回答留存。
- 游戏内半透明投影，沿视线调整距离、锁定定位、旋转、镜像和分层查看。
- 单机创造模式下的确认放置、取消和保护式撤销；撤销不会强制覆盖玩家之后的修改。
- 外层环境选区、内层改造选区和保护区域，支持读取环境、生成改造方案、预览和确认应用。
- 实验性参考图片输入、发送确认与来源绑定，需要所选 Agent 和模型明确支持图片。
- 默认关闭的有限容量恢复开关；仅新 Codex 组件任务可明确开启，恢复与失败共用原预算，未知或部分输出不重发，详见 [费用与恢复边界](docs/PROVIDER_RECOVERY.md)。

功能存在不等于完整验收通过。大型 CBD 外观品质、完整无人值守流程、多图融合质量、部分特殊方块通行和跨环境性能仍需继续验证，详见 [项目状态](docs/STATUS.md)。

最新阶段结果见 [2026 年 10 月 8 日免费流程验收](docs/FREE_FLOW_VERIFICATION_20261008.md)：四项模拟流程与原始证据核验通过，但不代替真实模型生成、光影投影像素可见性或正式发行版验收。

## 安装与使用

当前目标平台为 Windows x64、Minecraft Java 1.20.1、Fabric Loader 0.16.10 或兼容版本、Fabric API 0.92.5 加 1.20.1。开发构建使用 Java 17、Node.js 22.19.0 和 Gradle 8.12.1。

本仓库首次公开的是开发源码，不是已认证的正式二进制发行版。构建方法见 [开发指南](docs/DEVELOPMENT.md)。候选 JAR 内置本地 Bridge 和 Windows Node 运行时，玩家无需另外启动 Bridge；Minecraft、Fabric API 和制作所用 Agent 仍须自行安装，Agent 须完成自己的登录或 API 配置。

将构建得到的用户 JAR 和 Fabric API 放入实例的 `mods` 目录，启动单机创造模式世界，在控制设置中找到本模组的打开面板按键。先加载不调用模型的示例，检查投影和确认流程，再使用自己的 Agent。AI 生成可能消耗所选账户额度；图片和选区内容只应在确认接收模型与发送内容后发送。

不要把源码压缩包直接当成模组安装，也不要安装开发验收用的 QA JAR。测试前备份世界，暂不用于重要存档或多人服务器。

## 源码结构

| 目录 | 用途 |
| --- | --- |
| `mod` | Fabric 模组、客户端界面、投影和世界事务 |
| `bridge` | 本机回环服务、Agent 适配、任务与恢复记录 |
| `contracts` 和 `prompts` | 数据协议、校验规则和模型生成要求 |
| `src/design` 和 `src/generation` | 场景编译、组件拼装和原生建筑数据 |
| `src/world` | 环境快照、选区改造和保护规则 |
| `tests` | 免费离线回归和模拟故障测试 |
| `packaging` | 内置运行时打包与依赖声明 |
